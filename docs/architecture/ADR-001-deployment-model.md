# ADR-001: Deployment model

- **Status:** Proposed
- **Date:** 2026-10-16

## Context

Dedicated compute satellites maximize power and thermal control. Hosted payloads reduce early CAPEX and ride existing constellations.

## Decision

**Hybrid:** 2027 demonstrator as a **hosted payload** on a partner bus; keep a production path to **dedicated compute satellites**.

## Consequences

- ICDs must support both bus-hosted and dedicated-node interfaces.
- Partner RFI needed for power/thermal share on host bus.
- 2028+ evaluate dedicated nodes once workload and TCO are proven.
